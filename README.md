# 김상옥 · SW QA Engineer — Portfolio

발표용 슬라이드 덱 (단일 HTML, 외부 의존성 없음).

- **보기**: https://kx2471.github.io/portfolio/
- 파일 하나(`index.html`)로 동작하며 CSS·JS·이미지가 모두 인라인되어 있습니다.
- 검색엔진 색인은 차단되어 있습니다 (`noindex`). 링크를 아는 사람만 볼 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| `→` `Space` `PageDown` | 다음 장 |
| `←` `PageUp` | 이전 장 |
| `M` | 전체 목차 (검색 가능) |
| `Home` / `End` | 처음 / 마지막 |
| `Cmd+P` | 전체 슬라이드 PDF 저장 |

## 수정

`index.html` 하나만 교체한 뒤 커밋·푸시하면 1~2분 내 반영됩니다.
