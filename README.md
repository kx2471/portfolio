# 김상옥 · SW QA Engineer — Portfolio

**https://kx2471.github.io/portfolio/**

QA 프로세스 설계 · 테스트 자동화 · AI 도구 개발 기록.
테스트 리포트 형태로 구성했으며, 대표 작업은 태스크 창(모달)으로 열립니다.

## 구성

| 페이지 | 내용 |
|---|---|
| `index.html` | 리포트 — Summary · Cases · Verified · Career · Side · Contact |
| `process.html` | CASE-01 · QA 프로세스를 0에서 1로 |
| `automation.html` | CASE-02 · MLOps 파이프라인 무인 회귀 검증 |
| `runner.html` | CASE-03 · 테스트 러너 — 모두가 검증할 수 있는 환경 |
| `agent.html` | CASE-04 · AI Agent — Regression TC Creator |
| `practice.html` | CASE-05 · 검증 실무 — 산출물 · API 검증 · 업무 도구 |

## 기술

- 정적 HTML/CSS/JS · 빌드 도구 없음 · 외부 의존성 없음 (Pretendard 웹폰트만 CDN)
- 대표 작업 클릭 시 상세 페이지를 `fetch`로 불러와 모달로 표시 (JS 미지원 시 일반 페이지 이동)
- 검색엔진 색인 차단 (`noindex`)
- 실제 업무 화면이 포함되어 있으며, 고객사 · 담당자명 · 내부 주소 등은 비식별 처리했습니다.
